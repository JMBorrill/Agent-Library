# Start here

1. Read `README.md` (what the library is, what is and is not verified).
2. Run `python3 scripts/run_all_checks.py`.
3. To use on a project: `docs/INSTALL.md` (select → dry-run install → apply).
4. To find a capability: `docs/CAPABILITY_GUIDE.md`.
5. To see it working: `examples/` (three worked demonstrations, reproducible with `python3 examples/run_demos.py --check`).
6. To continue development: `docs/progress.md` (resume point), `docs/CONVENTIONS.md`, `docs/PACK_BUILDER_BRIEF.md`.

The original mission brief from the starter kit is kept in `docs/MASTER_CLAUDE_BUILD_PROMPT.md`.
