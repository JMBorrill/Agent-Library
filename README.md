# Agent-Library

A professional AI agent and skills library for Claude, grounded in pinned official framework sources:

| Framework | Edition | Skill(s) | CLI |
|---|---|---|---|
| NASA Systems Engineering Handbook | NASA/SP-2016-6105 Rev 2 | `nasa-systems-engineering`, `requirements-engineering` | `agentlib nasa-se` |
| NASA Software Engineering Requirements | NPR 7150.2D | `nasa-software-engineering` | `agentlib nasa-swe` |
| NASA Software Assurance & Software Safety | NASA-STD-8739.8B | `nasa-software-assurance` | `agentlib nasa-swe` |
| NIST AI Risk Management Framework + Playbook | AI 100-1 (1.0) | `nist-ai-rmf` | `agentlib ai-rmf` |
| NIST Secure Software Development Framework | SP 800-218 v1.1 | `nist-ssdf` | `agentlib ssdf` |
| OWASP Application Security Verification Standard | 5.0.0 | `owasp-asvs` | `agentlib asvs` |
| HM Treasury Green Book | 2026 | `green-book-appraisal` | `agentlib greenbook` |
| Cross-cutting | — | `evidence-and-citation`, `framework-selector` | `agentlib evidence`, `agentlib route` |

It is a **Claude Code plugin** (skills, subagents, slash commands), a set of **structured workflows** with stage
gates, and a **Python package** (`agentlib`) of deterministic tools — calculators, checklist generators,
validators and an evidence checker — backed by machine-readable catalogs extracted from the PDFs with page citations.

## Quick start

Install as a Claude Code plugin:

```text
/plugin marketplace add JMBorrill/Agent-Library
/plugin install professional-agent-library@jmborrill-agent-library
```

Or work from a checkout:

```sh
pip install -r requirements-dev.txt
python -m agentlib list                       # skills, agents, commands, workflows, catalogs
python -m agentlib route "security review of a payments API and its CI pipeline"
python -m agentlib asvs checklist --level 2 --format md
python -m agentlib greenbook npv evals/green-book-appraisal/fixtures/appraisal_flows.csv
python -m agentlib evidence check my-report.md --require-citations
```

Using the library in other repositories (plugin, vendored install with lock file, or CI tools):
**[docs/USING_IN_OTHER_REPOS.md](docs/USING_IN_OTHER_REPOS.md)**.

## What's inside

| Path | Contents |
|---|---|
| `skills/` | Agent Skills: procedure (`SKILL.md`), deep guidance (`references/`), artefact templates (`templates/`) |
| `agents/` | Specialist subagents (systems engineer, requirements engineer, software assurance engineer, AppSec verifier, secure development reviewer, AI risk assessor, AI governance advisor, economic appraisal analyst) and orchestrators (`review-board-chair`, `evidence-auditor`) |
| `workflows/` | Multi-stage, gated workflows: technical review gate, secure software delivery, AI system assurance, public investment business case, software assurance audit |
| `commands/` | Slash commands launching the workflows (`/technical-review`, `/secure-delivery-review`, `/ai-assurance`, `/business-case`, `/software-assurance-audit`, `/select-frameworks`, `/check-evidence`) |
| `catalog/` | Framework catalogs (requirements, tasks, subcategories, parameters) with PDF page citations, regenerated by `scripts/extract/` |
| `agentlib/` | Validators, registry, evaluation harness, installer and framework tools |
| `evals/` | Evaluation suites per skill: prompts, deterministic checks, golden and negative outputs |
| `sources/` | The pinned official PDFs and provenance manifest ([source index](sources/README.md)) |
| `registry.json` | Generated index of every component |

## Quality gates

```sh
python scripts/verify_source_pdfs.py   # pinned PDFs match manifest hashes
python -m agentlib validate            # structure, links, citations ranges, workflow wiring, evals, registry
python -m pytest                       # tools and core
python -m agentlib eval                # offline skill evals: goldens pass, negatives fail
claude plugin validate .               # Claude Code plugin manifest
```

All run in GitHub Actions (`.github/workflows/validate.yml`). Live model evaluations
(`python -m agentlib eval --mode live`) run on demand via `live-evals.yml` with an `ANTHROPIC_API_KEY` secret.
See [docs/EVALUATION.md](docs/EVALUATION.md).
