# Se Technical Planning

## When to use
Tailor an engineering plan to project size, risk, budget, milestones and review readiness.

## Procedure
1. Classify project risk and complexity before choosing the depth of process.
2. Produce a product/work breakdown structure, milestones, dependencies and staffing constraints.
3. Define document baselines, ownership, decision rights, cost/schedule reserves and evidence retention.
4. Set entry and exit criteria for reviews proportional to actual risk.
5. Surface critical paths and underspecified work without inventing certainty.

## Required outputs
engineering-plan.md, milestone-plan.md, responsibility-matrix.md

## Evidence and quality gates
- Cite applicable source IDs from `sources/registry.json` and document specific sections where verified.
- Identify each assumption, unresolved question, owner and review status.
- No fabricated observations, approvals, compliance conclusions or test evidence.
- For safety-critical or regulated decisions, escalate to a qualified human reviewer.
