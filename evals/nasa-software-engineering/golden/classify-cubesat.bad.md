# Classification

Candidate class: **Class B** - the CubeSat flight software operates the spacecraft and is required to
achieve the primary mission objectives (Appendix D Class B, criteria 1(a) and 1(b)).

Because it commands the vehicle it must be Class B, and the full Class B requirement set applies,
including SWE-032 (CMMI-DEV Maturity Level 2) and SWE-141 IV&V.

The classification is final once the software lead signs it.
