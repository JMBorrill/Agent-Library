# Tailoring request routing - Class B project

The project wants relief from SWE-141 (software IV&V) and SWE-032 (CMMI-DEV rating). Both are marked X for
Class B in Appendix C, so relief is tailoring of an "X" requirement and needs the approval of the Authority
named in Appendix C (NPR 7150.2D 2.2.5) [nasa-software-requirements SWE-150, p. 19].

| SWE | Appendix C Authority | Who decides | Source |
|---|---|---|---|
| SWE-141 | HQ OSMA | The NASA Chief, SMA makes the final decision on all proposed tailoring of SWE-141 (SWE-223) | [nasa-software-requirements Appendix C SWE-141, p. 62] [nasa-software-requirements SWE-223, p. 12] |
| SWE-032 | HQ OCE and HQ OSMA | NASA HQ (OCE and OSMA); a tailored request on an HQ TA requirement needs NASA HQ approval | [nasa-software-requirements Appendix C SWE-032, p. 66] [nasa-software-requirements SWE-126, p. 17] |

What the request must contain:

- Rationale, a risk evaluation and reference to all supporting material; the dispositioning organization
  obtains concurrence from organizations that could be affected (Note to 2.2.5, pp. 18-19).
- It can be submitted in the streamlined form of the Requirements Mapping Matrix with the engineering,
  CIO and SMA signatures (2.2.6, p. 19); the approving authorities sign in the matrix (SWE-126 b).
- The responsible project manager formally accepts the tailoring risk (2.2.1).
- Once approved, reflect the tailoring in the plans (SWE-121) [nasa-software-requirements SWE-121, p. 22]
  and keep it in the matrix (SWE-125) [nasa-software-requirements SWE-125, p. 22].

For SWE-032 note the Class B "best in class provider" exception: an evaluation against CMMI-DEV Maturity
Level 2 practices by a qualified evaluator selected by the Center ETA, with OCE and Center ETA notified
[nasa-software-requirements SWE-032, p. 28].

Neither the project nor the Center ETA can grant this relief alone; this note prepares the request, it
does not approve it.
