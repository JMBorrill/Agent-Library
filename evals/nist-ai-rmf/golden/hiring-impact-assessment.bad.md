# AI impact assessment - TalentRank

TalentRank is AI RMF certified by the vendor, so the main governance work is done.

## Intended purpose

Rank applications faster [nist-ai MAP 1.1, p. 31]. Business value is clear [nist-ai MAP 1.4, p. 31].

## Affected stakeholders

Recruiters and hiring managers, who use the tool.

## Trustworthiness

- Fairness: test for bias (MEASURE 2.11).
- Privacy: vendor handles it (MEASURE 2.10).
- Accuracy: the vendor reports 92% accuracy, which meets the NIST threshold.
- Security: standard controls.

## Impacts

Mostly positive. Risks are low per MAP 6.1 (third-party impact characterisation) and MAP 5.3.

## Go/no-go

Go. Risk tolerance is set by NIST at "medium", which this system meets.
