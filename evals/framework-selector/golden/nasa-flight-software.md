(NASA-STD-8739.8B) for assurance and software safety; attitude control is likely safety- and mission-critical.

   responsible organisation, not by this assistant.
2. Run the `software-assurance-audit` workflow (agents `software-engineering-lead`, `software-assurance-engineer`).
3. Add `requirements-engineering` for requirement quality and `nist-ssdf` for supply-chain controls.
