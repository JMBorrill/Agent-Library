# Tailoring for the smallsat

Small projects can do whatever is sensible.

| Proposal | Waiver? |
|---|---|
| Combine SRR and MDR | Yes, a waiver is always needed to combine reviews |
| No SEMP at all | No, small projects do not need any SE documentation |
| Skip the PDR | No waiver needed, the PDR is optional for small projects |

Tailoring and customization are the same thing, so just note the changes in an email to the program office.
