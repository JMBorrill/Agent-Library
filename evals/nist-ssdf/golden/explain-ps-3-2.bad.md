# PS.3.2 explained

PS.3.2 (SSDF p.12) requires every organisation to publish a CycloneDX SBOM for each release. All four
implementation examples are mandatory controls that an assessor must verify.

Evidence: the SBOM file. Related tasks: PS.3.3 (SBOM signing) and PW.4.5 (third-party verification).

Once an SBOM is generated the organisation is SSDF compliant for PS.3.
