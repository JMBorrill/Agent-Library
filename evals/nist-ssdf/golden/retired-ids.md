# Mapping legacy SSDF identifiers to SSDF v1.1

The questionnaire uses identifiers that SSDF v1.1 (NIST SP 800-218, February 2022) has retired. Table 1 keeps
them only as "Moved to ..." pointers and the Change Log (PDF p.36) records the moves. Use the current ids.

| Legacy id | Status in v1.1 | Use instead | Source |
|---|---|---|---|
| PW.3.1 | Retired - moved | PO.1.3 (communicate requirements to third parties providing commercial components) | Table 1 PDF p.21; PO.1.3 "[Formerly PW.3.1]" PDF p.14 |
| PW.4.5 | Retired - moved | PW.4.1 and PW.4.4 (acquire well-secured components; verify third-party components comply) | Table 1 PDF p.22 |
| PW.5.2 | Retired - moved | PW.5.1 (now an implementation example of secure coding practices) | Table 1 PDF p.22 |

Other retired ids you may meet: PW.3 (practice merged into PW.4), PW.3.2 (now PW.4.4), PW.4.3 (now PW.1.3).

Recommended questionnaire wording: ask suppliers to answer against PO.1.3, PW.4.1, PW.4.4 and PW.5.1, and to
reference SSDF v1.1 explicitly so answers are not mapped to retired numbering.

This mapping supports, but does not replace, qualified professional judgement.
