# CLAUDE.md — working on the Agent Library

This repository is a Claude Code plugin and Python package (`agentlib`) containing framework-grounded
skills, subagents, workflows, catalogs and tools. Read `docs/AUTHORING.md` before adding or changing a component.

## Commands

```sh
pip install -r requirements-dev.txt
python -m agentlib validate          # structural validation (must be clean)
python -m pytest                     # unit/integration tests
python -m agentlib eval              # offline skill evals (goldens pass, negatives fail)
python -m agentlib registry --write  # regenerate registry.json after adding/renaming components
python scripts/verify_source_pdfs.py # pinned source integrity
```

## Rules

- Never cite framework content from memory: read the pinned PDF page (`pdftotext -f N -l N -layout ...`) and cite
  `[source-id locator, p. N]` (PDF page). Never invent requirement ids, thresholds or page numbers.
- Calculations and checklist scoping go in deterministic tools under `agentlib/frameworks/`, with tests.
- Catalogs are generated by `scripts/extract/*.py`; regenerate rather than hand-edit.
- Keep `SKILL.md` under 500 lines; push detail into `references/`.
- Outputs must not claim certification, compliance or approval; decisions belong to accountable humans.
