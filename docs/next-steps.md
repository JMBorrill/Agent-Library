1. **Validate expert accuracy:** verify source sections manually; compare outputs to human-reviewed gold examples. Add per-skill eval tests.
2. **Complete NASA pack:** map each of NASA's 17 processes to skill actions and artifact/test schemas; automate parent-child and requirement-test coverage checks.
3. **Product:** add service blueprint, experiments, shaping/pitches, accessibility and design-system testing. Use GOV.UK manuals and Shape Up as separate sources and note their tension/contexts.
4. **Software:** add architecture decisions, OWASP ASVS controls, CI test engineering, SRE runbooks, postmortem and DORA metrics. Use source-appropriate licensing.
5. **Finance:** add SaaS unit economics, funding/risk sensitivity, credit risk, UK consumer finance regulatory mapping with date/version, independent reviewer.
6. **Governance:** add source-refresh reminders, license checks, automatic version references, prompt injection defenses and red-team evals.
7. **Portability:** build a packaging script to install selected Agent Skills into tool-specific conventions. Keep skills tool-agnostic; keep Claude Code subagent files separate.

Do not imply auto-generated documents represent formal certification. Human experts are needed for engineering safety and legally regulated products.
