### `assurance-case` (quality, beta, v1.0.0)

Builds and checks a structured assurance case (claims, arguments, evidence) that ties framework results together for a decision-maker: e.g. "the payments API is acceptably secure for release", argued through ASVS verification, SSDF process evidence and residual-risk acceptance. A deterministic checker (python -m agentlib assurance-case check) enforces one root claim, no cycles, every leaf claim backed by evidence of adequate strength or explicitly undeveloped with justification, and real framework identifiers. Use when preparing a release, safety, security or AI deployment decision package, or when a review board needs one argument that integrates several assessments.

- Sources: `nasa-se`, `nasa-software-assurance`, `owasp-asvs`
